How Payouts Work

Per Game & Series Total

Each bowling night has 4 betting opportunities: Game 1, Game 2, Game 3, and the Series Total (sum of all 3 games). Each works the same way:

  • Every player puts in $2 per game/series
  • Highest score (with handicap) wins the pot
  • Ties split the winnings

Payout Scenarios

Sole Winner (1 winner, 3 losers)
Winner receives $2 from each loser = +$6
Each loser pays = -$2
Two-Way Tie (2 winners, 2 losers)
Each winner receives $2 from each loser, split between them = +$2 each
Each loser pays = -$2
Three-Way Tie (3 winners, 1 loser)
Each winner receives $2 from the loser, split three ways = +$0.67 each
The loser pays = -$2
Four-Way Tie (everyone ties)
No money changes hands = $0 for everyone

Maximum Winnings Per Night

If one player wins all 4 (Game 1, Game 2, Game 3, and Series Total), they'd win $24 total ($6 x 4). Each loser would be down $8 ($2 x 4).
